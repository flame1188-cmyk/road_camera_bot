# Данные НП БДД (Тр — deaths per 10,000 vehicles)

Эта папка содержит JSON-файлы с нормативными данными для расчёта показателя Тр.
**Все файлы ДОЛЖНЫ быть закоммичены в Git и попадать в Docker-образ.**

## ⚠️ Почему `datasets/`, а не `data/`

Папка намеренно переименована из `data/` в `datasets/`, потому что хостинг Bothost
«съедает»/монтирует пустой persistent volume поверх любых папок с именем `data/`
внутри Docker-образа. Использование имени `datasets/` обходит это поведение.

Корневая папка `data/` (для основного бота: кэш камер, OSM и т.д.) по-прежнему
используется как persistent volume и не коммитится в Git — см. `.gitignore`.

```
│   └── 1182.json     # Челябинская область

```

## Почему эти файлы в репозитории

Эти JSON-файлы — **нормативные данные**, а не кэш и не пользовательские данные.
Они:
- нужны для работы модуля НП БДД в Mini App;
- одинаковые для всех инсталляций бота;
- версия-контролируются вместе с кодом;
- НЕ должны попадать в `.gitignore` или `.dockerignore`.

## Страховка: embedded_data.py

Все JSON-файлы из этой папки дополнительно встроены в Python-модуль
`np_bdd/scripts/embedded_data.py` (генерируется скриптом
`/home/z/my-project/scripts/generate_embedded_data.py`). При запуске
сервиса, если `datasets/` пустая, встроенные данные автоматически
распаковываются на диск. Это финальная страховка на случай, если
какой-то хостинг всё-таки «съедает» папку.

При обновлении JSON-файлов запустите регенерацию:
```bash
python3 /home/z/my-project/scripts/generate_embedded_data.py
```
и закоммитьте обновлённый `embedded_data.py`.
